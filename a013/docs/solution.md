# a013: 羅馬數字

## 1. 題目理解與規格分析
- **題目連結**：ZeroJudge [a013: 羅馬數字](https://zerojudge.tw/ShowProblem?problemid=a013)
- **題目描述**：
  讀入兩個羅馬數字 $A$ 與 $B$，計算兩數差的絕對值 $|A - B|$，並以標準羅馬數字格式輸出結果。
  若差為 0，則輸出字串 `ZERO`。
  羅馬數字採用標準減法化簡規則（連續四個相同符號出現時，改用減法規則簡化，例如 4 為 IV、9 為 IX 等）。
- **輸入規格**：
  每個輸入檔包含一筆或多筆測試資料。
  每一行由兩個以空格分隔的羅馬數字字串組成，數值均小於 4,000。
  檔案以單獨的 `#` 符號標記結束。
- **輸出規格**：
  每筆測試資料輸出一行對應差值之羅馬數字表示，若值為 0 則輸出 `ZERO`。
- **限制條件**：
  - 數值小於 4,000
  - 時間限制：1.0 秒
  - 記憶體限制：64 MB

## 2. 演算法設計與推導

### 2.1 羅馬數字符號與數值對應
基本符號：
| 符號 | 數值 |
| :--: | :--: |
| I | 1 |
| V | 5 |
| X | 10 |
| L | 50 |
| C | 100 |
| D | 500 |
| M | 1,000 |

減法合成符號（避免連續 4 個相同符號）：
- IV: 4, IX: 9
- XL: 40, XC: 90
- CD: 400, CM: 900

### 2.2 羅馬數字轉整數 (`roman_to_int`)
遍歷字串中的每個字元：
- 設目前字元為 $S[i]$，其數值為 $v_i$。
- 若後續字元 $S[i+1]$ 存在且其數值 $v_{i+1} > v_i$，則表示為減法規則（如 IV, IX, XL 等），總和減去 $v_i$。
- 否則，總和加上 $v_i$。
- 時間複雜度為 $O(|S|)$，因長度 $|S| \le 15$，轉換耗時約十幾次運算，幾乎為瞬間完成。

### 2.3 整數轉羅馬數字 (`int_to_roman`)
對於差值 $D = |A - B|$：
- 若 $D = 0$，直接返回 `"ZERO"`。
- 若 $D > 0$，使用貪婪法（Greedy），由大至小嘗試扣除以下數值及其對應羅馬數字：
  `(1000, "M"), (900, "CM"), (500, "D"), (400, "CD"), (100, "C"), (90, "XC"), (50, "L"), (40, "XL"), (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I")`
- 每次當 $D$ 大於等於該權重時，追加對應字串並扣除相應數值，直到 $D = 0$。

### 2.4 SoC 與純函數架構設計
- **核心解題層 (`solver.hpp`)**：
  - `roman_to_int`：純函數，無任何全域狀態。
  - `int_to_roman`：純函數，將整數轉換為羅馬字串。
  - `solve`：接受 `Input { s1, s2 }`，計算 $|roman\_to\_int(s1) - roman\_to\_int(s2)|$ 並轉為字串回傳 `Output`。
- **I/O 處理層 (`io_handler.hpp`)**：
  - 使用 `zj::FastIO` 高效讀取字串 token。
  - 當遇到 EOF 或讀取到的第一個 token 為 `#` 時，返回 `false` 終止迴圈。
- **組裝進入點 (`main.cpp`)**：
  - 標準 EOF 迴圈串接 I/O 與解題器。

## 3. 複雜度分析
- **時間複雜度**：
  每筆測資字串長度最大約 15，單筆測資時間為 $O(|S_1| + |S_2|) = O(1)$。
  整體效率極高，處理數萬筆測資亦可在數毫秒內完成。
- **空間複雜度**：
  $O(1)$ 常數額外空間，僅存儲暫存字串。

## 4. 邊界測試案例
1. **差為零**：`I I` $\to$ `ZERO`
2. **範例案例**：`MM II` $\to$ `MCMXCVIII` ($|2000 - 2| = 1998$)
3. **被減數小於減數**：`II MM` $\to$ `MCMXCVIII`
4. **邊界最大值與極端差值**：`MMMCMXCIX I` $\to$ `MMMCMXCVIII` ($3999 - 1 = 3998$)
5. **減法規則綜合測試**：`IX IV` $\to$ `V` ($9 - 4 = 5$)
6. **結束條件驗證**：輸入末尾 `#` 正確停止退出。
