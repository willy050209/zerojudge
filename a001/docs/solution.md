# a001: 哈囉

## 1. 題目理解與規格分析
- **題目連結**：ZeroJudge [a001: 哈囉](https://zerojudge.tw/ShowProblem?problemid=a001)
- **題目描述**：學習所有程式語言的第一個步驟，基本上就是要在螢幕上印出「hello, world」。現在請你寫一個程式，輸入文字字串，並在字串前加上「hello, 」。
- **輸入規格**：輸入包含多行字串，每行代表一個名字或字詞。未指定行數，讀取至 EOF 為止。
- **輸出規格**：每行輸出 `hello, {name}`。
- **測資範圍與限制**：
  - 時間限制：1 秒
  - 記憶體限制：64 MB
  - 單字長度通常在 100 字元以內。

## 2. 演算法思路與設計推導
- **核心想法**：
  本題屬於字串格式化與串接問題。針對每行輸入字串 $S$，輸出前綴 `"hello, "` 並串接 $S$。
- **關注點分離 (SoC) 與純函數設計**：
  - **I/O 處理層 (`io_handler.hpp`)**：使用 `zj::FastIO` 或 `std::cin` 逐行或逐詞讀取字串，偵測 EOF 訊號。
  - **核心解題層 (`solver.hpp`)**：純函數 `solve(const Input& in) -> Output`，只負責接收字串，返回格式化好的字串，保證無 I/O 副作用。
  - **格式輸出層 (`main.cpp`)**：將純函數結果透過 `zj::FastIO::println` 輸出。

## 3. 複雜度分析
- **時間複雜度**：$O(L)$，其中 $L$ 為每筆測資的字串長度，單筆耗時微秒級。總時間遠低於 1.0 秒。
- **空間複雜度**：$O(L)$，僅需存放輸入與輸出字串。

## 4. 邊界測試案例與極限驗證
- **邊界 1**：單一字元，如 `"a"` -> `"hello, a"`
- **邊界 2**：包含數字或符號，如 `"world_2026"` -> `"hello, world_2026"`
- **邊界 3**：多筆連續測資（驗證 EOF 正確退出）
